# AI 티 나는 표현·구조 목록 (사용자 지정 블록리스트)

> 이 목록은 **탐지 힌트**다. 게이트가 아니다. 여기 든 표현이 나왔다고 기계적으로
> 치환하지 말 것 — 치환은 또 다른 기계다. 문단을 목소리로 다시 쓴다. (SKILL.md §3·§4)
> 목록은 대표 항목만 든다. 새 말버릇을 만나면 아래 패턴 중 하나로 분류해 처리한다.

## 3. 구조적 패턴

- 간단한 질문에 원인 분석 전체를 붙임

- 평범한 사실에 "중대한", "중요성", "전환점" 같은 의미 부여
- 추상적인 대상에 위 / 레이어 / 척추 / 등뼈 / 해자 / 두께 같은 물리적 은유 사용

## 5. 지시어 남발
- 이것, 그것 / 이것이, 그것이, 그것들이
- 이 작명, 이 회사, 이 사실
- 그 농담이, 그 노력, 그 끝자락
- 이 책, 이 문장, 이 원고 (같은 대상을 반복 지시)

> **처리 규칙 (이걸 "정상 조응이라 유지"로 넘기지 말 것 — 그게 반복된 합리화다):**
> ① **기본은 드롭.** 앞 문맥으로 대상이 명확하면 `이/그`를 통째로 뺀다.
>    `이 구분은`→`구분은`, `그 되풀이가`→`되풀이가`, `이 대목에서`→(삭제), `이 책을 쓰는 언어`→`쓰는 언어`.
>    "이게 꼭 붙어야 하나?"를 매번 묻는다. 안 붙어도 통하면 뺀다.
> ② 못 빼면 **구체 지시로 치환** (그것→그 특징·그 절차, 그 사람들→그들).
> ③ **어쩔 수 없는 조응만 남긴다** (한 무리를 계속 가리켜야 하는 `그들`, 특정 대상 `그 숫자들`).
> ④ **문단마다 그/이 개수를 세는 밀도 지도**를 만든다(4개+ 문단 = 손볼 것). 인상으로 넘어가지 말 것.
> ⑤ grep `이 [가-힣]` 전체 수는 **주격조사 오탐**(예: "대목이 있다"의 대목이)이니 믿지 말고 눈으로 지시어만 센다.
> 예외: 인용·예문 속 지시어(어텐션 예문의 "'그것'이 책인지")는 내용이라 유지.

## 6. 문장부호 · 병기 tell

> 부호(— – ·)는 md 파싱으로 잡을 수 없어 **게이트가 코드로 직접 센다**.
> 여기 목록은 사람용 참조.

- — (em dash) 남발
- – (en dash)
- · (미들닷 / interpunct) — em·en dash처럼 남발되는 부호 tell
- <English word> 계열로 영어 단어를 습관적으로 병기

## 7. 강조어 (사용자 확정: 굳이 쓰지 않는다)
- 훨씬 / 매우 / 아주 / 무척 / 굉장히 / 너무나 / 더욱 / 몹시

## 8. 가짜 강조 · 예고 (사용자: "그닥 안 중요해")
- 중요한 것은 / 핵심은 / 눈여겨볼 / 주목할 것 / 결정적인

## 9. 메타 선언 — 글이 글 쓰는 행위를 중계하는 문형 (사용자: "안 읽혀")
- 적어 둔다 / 적어 두 / 적어야 한다
- 써 두어야 / 써 둘 / 기록해 두 / 기록해 둘
- 말해 두 / 말해야겠다 / 말해야 한다 / 밝혀 두 / 일러두
- 덧붙여 둘 / 덧붙여 두 / 짚어 두 / 짚고 가야
- 할 차례다 / 이야기를 해야 / 이야기로 갈

> 처리: 문형을 지우고 내용으로 바로 시작한다. "이 반복에 대해 덧붙여 둘 사실이
> 있다. 매 조각마다 X다" → "매 조각마다 X다".

## 10. 의인·물리 은유 서술 (기계·추상 주어에)
- 그물 / 물살 / 시선의
- 통과하 / 스며 / 깎였 / 깎아 / 눌려 / 눌린 / 새겨졌 / 새겨진

> "숫자들이 통과하는 구조" 같은 문장 금지. 기계 동작은 직접 서술로.
> 이 항목은 내용(실제 물·조각 묘사)과 겹칠 수 있으니 발췌를 읽고 판정.

## 11. 정정 골격 · 선언 연쇄 (게이트가 코드로 직접 잡는다 — 사람용 참조)
- "A가 아니라 B다" — 기본 전면 해체. B를 직접 서술. (인용문 속, 문자 그대로의
  사실 부정만 사유를 적고 잔존)
- 짧은 선언문 3연속+ — "나는 리모컨이다. 리모컨은 나다. 그러기 위해 나는
  눌린다."처럼 한 생각을 쪼개 선언으로 착지시키는 것. 한 문장으로 접는다.
  같은 명제의 도치 재선언("저자이면서 동시에 독자다" 류)도 같은 병.

## 12. 문두 접속부사 (2026-08-20 사용자 확정 — 게이트가 코드로 잡는다)
문장 첫머리의 논설문 접속부사는 조립의 흔적이다. 경성(그러나·따라서·또한·그러므로·한편·하지만)은 기본 제거 — 앞 문장에 어미(~지만/~니/~고/~는데)로 접는다. 연성(그리고·그런데·그래서)은 말의 호흡이므로 허용하되 과밀만 경계.
